## 📖 Latar Belakang & Misi Proyek

Di era digital saat ini, maraknya platform judi online (judol) telah merusak tatanan ekonomi, psikologis, dan masa depan banyak orang di Indonesia. Banyak korban terjerat karena ilusi bahwa mereka bisa "menang besar dan kaya mendadak", tanpa menyadari bahwa sistem di balik layar telah **dimanipulasi secara sistematis agar bandar selalu menang (*The House Always Wins*)**.

**Judoru45_Game** hadir sebagai platform web simulasi interaktif edukatif yang:
1. 🛑 **Membongkar Manipulasi Algoritma Bandar**: Mengizinkan pengguna/dosen/juri melihat langsung dari sudut pandang admin bagaimana probabilitas kemenangan dan kekalahan diatur secara sepihak.
2. 💰 **100% Uang Virtual (Tanpa Deposit Nyata)**: Memberikan pengalaman bermain sepuasnya menggunakan koin virtual gratis dengan tombol *Instant Faucet Reload* tanpa perlu top-up sepeser pun.
3. 🧠 **Edukasi Psikologis**: Mengonversi koin virtual yang hilang menjadi barang kebutuhan nyata (*"Uang yang hilang setara dengan X karung beras / Y bulan cicilan motor / Z semester kuliah"*).

Setiap game dibuat dengan animasi dinamis, efek visual modern, dan mesin suara prosedural **Web Audio Synth** (*zero external sound asset lag*):

| **⚡ Slot Olympus (Zeus Style)** | Grid 5x3, animasi reels berputar, paylines otomatis, petir perkalian multiplier 2x–500x, dan mode *Scatter Free Spins*. |

## 🚀 Menjalankan Secara Lokal (Local Development)

### 1. Clone Repository
```bash
git clone https://github.com/triwahyu45/Judoru45_Game.git
cd Judoru45_Game
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Jalankan Development Server
```bash
npm run dev
```
Buka browser di [`http://localhost:3000`](http://localhost:3000).

### 4. Build Production
```bash
npm run build
```
